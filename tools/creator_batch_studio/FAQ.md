# Creator Batch Studio v1.0 — FAQ

## Mes images sont-elles envoyées sur Internet ?
Non. Le traitement est effectué localement sur l'ordinateur.

## Quels formats sont acceptés en entrée ?
JPG/JPEG, PNG, WebP, BMP, TIFF/TIF.

## Quels formats sont proposés en sortie ?
WebP, JPG et PNG.

## L'application recadre-t-elle mes images ?
Les presets sociaux exacts placent l'image dans le cadre sans la couper. Le preset Web conserve les proportions et limite la taille maximale.

## Mes fichiers d'origine sont-ils remplacés ?
Non. Les exports sont créés dans le dossier de sortie et les collisions de noms génèrent un nouveau nom.

## Que se passe-t-il avec une image corrompue ?
Le traitement continue pour les autres images et l'erreur est enregistrée dans `creator_batch_report.json`.

## Faut-il une clé API ou un abonnement ?
Non pour la v1.0. L'application fonctionne sans compte externe ni clé API.

## Windows affiche-t-il un avertissement ?
Un exécutable non signé peut déclencher SmartScreen. Ne contournez pas un avertissement si le fichier ne provient pas du canal officiel. Une signature de code pourra être ajoutée à une version commerciale ultérieure.
