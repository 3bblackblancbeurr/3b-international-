# Creator Batch Studio v1.0 — Démarrage rapide

1. Lancez `CreatorBatchStudio.exe`.
2. Cliquez sur **Images…** ou **Dossier…** pour sélectionner vos visuels.
3. Choisissez un dossier de sortie.
4. Sélectionnez le format : WebP, JPG ou PNG.
5. Choisissez les tailles souhaitées : original, Instagram, TikTok/Reels, YouTube ou Web.
6. Cliquez sur **Créer les exports**.
7. Les fichiers sont rangés par preset et un rapport `creator_batch_report.json` est créé.

## Conseils

- Conservez vos originaux : l'application ne les modifie pas.
- WebP est recommandé pour le web lorsque la compatibilité le permet.
- En cas de fichier corrompu, le lot continue et l'erreur est inscrite dans le rapport.
- L'application fonctionne localement : aucun visuel n'est envoyé vers un serveur.

## Vérification du téléchargement

Le ZIP officiel est accompagné d'un fichier SHA-256. Il permet de vérifier que l'archive n'a pas été altérée.
