# Pipeline assets 3B

## Blender
- landmarks uniques ;
- props ;
- optimisation ;
- UV ;
- retopologie ;
- collisions simples.

## Houdini
- réseau routier ;
- trottoirs ;
- parcelles ;
- façades modulaires ;
- variantes ;
- génération par district.

## Substance 3D
- béton ;
- verre ;
- métal noir ;
- or champagne ;
- pierre ;
- textile ;
- zellige ;
- routes mouillées ;
- usure maîtrisée.

## RealityCapture / RealityScan
Réservé aux éléments où le scan apporte un vrai gain : roche, surface, objet patrimonial, texture de référence.

## Règles d'import
- unités centimètres ;
- pivot documenté ;
- noms stables ;
- collisions séparées lorsque nécessaire ;
- textures PBR ;
- LOD/HLOD testés ;
- aucun asset « final » non mesuré en jeu.
