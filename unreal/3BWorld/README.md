# 3B World — LEGACY / FROZEN MIGRATION SOURCE

> **Do not add new runtime, gameplay or backend work here.**
> The canonical UE5.8 project is now `../ThreeBWorld`.

This directory is preserved temporarily because it contains the original preproduction contracts, manifests, scripts and documentation used to prepare the migration.

Those useful resources are being copied into the canonical project. The old `ThreeBBackendSubsystem` is intentionally not part of the canonical runtime because its publishable-key/access-token model has been superseded by the one-time-ticket Unreal bridge.

Deletion is blocked until the canonical project compiles in Unreal Engine 5.8 and the migration checklist in `../ThreeBWorld/Docs/CONSOLIDATION_STATUS.md` is fully verified.

The web / Three.js world remains a functional fallback while the Unreal vertical slice is validated.
