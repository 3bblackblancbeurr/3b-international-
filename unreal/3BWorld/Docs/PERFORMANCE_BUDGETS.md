# Budgets initiaux — à mesurer

Ces nombres sont des objectifs de départ, pas des garanties.

## PC
- 60 FPS cible ;
- frame budget 16,67 ms ;
- qualité forte ;
- six cellules actives maximum au départ.

## Mobile haut de gamme
- 45–60 FPS lorsque possible ;
- quatre cellules actives au départ ;
- résolution dynamique ;
- ombres et foule adaptatives.

## Mobile moyen
- 30 FPS stable ;
- trois cellules actives au départ ;
- foule réduite ;
- FX réduits ;
- intérieurs lourds isolés.

## Mesures obligatoires
- Game Thread ;
- Render Thread ;
- GPU ;
- draw calls ;
- triangles ;
- mémoire textures ;
- streaming ;
- shader hitches ;
- temps de chargement ;
- pics de mémoire.

Aucune mention « optimisé » sans capture de mesures.
