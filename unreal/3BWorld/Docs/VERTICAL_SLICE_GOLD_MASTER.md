## Critères de sortie

La slice n'est pas Gold Master tant que tous les points suivants ne sont pas vérifiés :

- compte A ne voit jamais le Passeport du compte B ;
- Ville existante prioritaire sur tout ancien verrou ;
- aucune récompense sensible validée uniquement par le client ;
- 60 FPS cible PC sur machine de référence ;
- 30 FPS stable sur profil mobile moyen retenu ;
- aucun hitch majeur lors d'un changement de cellule ;
- cinématique → gameplay sans écran noir non intentionnel ;
- train utilisable ;
- PNJ narratif animé et interactif ;
- Souvenir persistant après fermeture ;
- Ville 3B restaurée après reconnexion ;
- première construction persistante ;
- test de changement de compte ;
- test hors-ligne / reprise ;
- test perte réseau pendant synchronisation.
