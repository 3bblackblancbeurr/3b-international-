# Convention de nommage 3B World

## Blueprints
- `BP_3B_`

## Static Meshes
- `SM_3B_`

## Skeletal Meshes
- `SK_3B_`

## Materials
- `M_3B_`

## Material Instances
- `MI_3B_`

## Textures
- `T_3B_`

## Niagara
- `NS_3B_`

## Level Sequences
- `LS_3B_`

## Data Assets
- `DA_3B_`

## Data Layers
- `DL_3B_`

## PCG Graphs
- `PCG_3B_`

## HLOD Layers
- `HLOD_3B_`

## Maps
- `L_3B_`

## Exemples

- `SM_3B_TowerBrokenCircle_Blockout`
- `SM_3B_ArchivesMemory_Exterior`
- `MI_3B_Road_Wet`
- `NS_3B_MatrixRain`
- `LS_3B_WorldOpening`
- `DL_3B_Docks`

Les IDs serveur restent indépendants : `tower_circle`, `memory_archives`, etc. Ne jamais remplacer l'ID serveur par le nom d'asset Unreal.
