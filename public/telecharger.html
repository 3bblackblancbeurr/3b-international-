3B International

Installe l’application officielle 3B sur ton téléphone. Aucun code d’invitation n’est demandé pour l’installation.

Installation iPhone

  1. Ouvre cette page dans Safari.
  2. Appuie sur Partager, puis Sur l’écran d’accueil.
  3. Active Ouvrir comme app si l’option apparaît, puis appuie sur Ajouter.

Installation depuis le navigateur

Sur Android, ouvre cette page dans Chrome ou Samsung Internet puis utilise l’option Installer l’application ou Ajouter à l’écran d’accueil.
