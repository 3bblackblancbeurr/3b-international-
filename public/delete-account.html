Supprimer mon compte 3B

Cette page est le moyen web officiel pour demander la suppression d’un compte 3B International, y compris depuis un navigateur sans utiliser l’application installée.

Comment ça fonctionne ?

  1. Saisis l’identifiant 3B et le mot de passe du compte concerné.
  2. Écris SUPPRIMER dans le champ de confirmation pour éviter une action accidentelle.
  3. Le site vérifie la session du compte, puis envoie la demande de suppression au service 3B prévu à cet effet.
  4. En cas de succès, la session locale 3B de ce navigateur est supprimée et un message de confirmation s’affiche.
Suppression définitive. La suppression entraîne la fermeture du compte et la suppression des données directement rattachées au compte. Cette opération ne peut pas être annulée.

Pour éviter une suppression accidentelle, saisissez exactement SUPPRIMER.

Pour comprendre comment 3B traite les informations personnelles, consultez la politique de confidentialité.
