Installer 3B sur iPhone.
Sans invitation.

La méthode la plus rapide fonctionne directement avec Safari : 3B s’ajoute à l’écran d’accueil et s’ouvre ensuite comme une application web dédiée.

Vérification de ton appareil…

✓ Installation détectée. Tu peux lancer 3B depuis son icône sur l’écran d’accueil.
Ouvrir 3B maintenant

3 gestes dans Safari

Tu es sur iPhone, mais pas dans Safari.
Appuie sur “Copier le lien”, ouvre Safari, colle l’adresse puis continue avec les étapes ci-dessous.
1
Ouvre cette page dans Safari.
Utilise Safari sur l’iPhone ou l’iPad.
2
Appuie sur Partager → Sur l’écran d’accueil.
Si l’option n’apparaît pas, fais défiler les actions du menu Partager.
3
Active “Ouvrir en app web” si proposé, puis Ajouter.
L’icône 3B apparaît ensuite sur l’écran d’accueil.

Adresse officielle : https://3b-international.vercel.app/install-iphone.html
