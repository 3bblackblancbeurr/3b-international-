Installer 3B International sur Android

Cette page explique la méthode officielle actuelle pour accéder rapidement à 3B International — Black • Blanc • Beur sur un téléphone Android. L’installation web conserve l’accès à l’application depuis une icône dédiée sur l’écran d’accueil.

Installation depuis Chrome

  1. Ouvrez 3b-international.vercel.app dans Chrome.
  2. Ouvrez le menu du navigateur.
  3. Choisissez Installer l’application ou Ajouter à l’écran d’accueil si l’option apparaît.
  4. Confirmez. L’icône 3B International apparaît ensuite sur le téléphone.

Après installation, ouvrez 3B depuis cette icône. Si une ancienne icône reste visible après une mise à jour, supprimez l’installation précédente puis installez de nouveau l’application afin que le téléphone recharge les ressources récentes.

Ce que l’installation change

L’installation web ajoute 3B International à l’écran d’accueil et permet de relancer l’expérience comme une application, sans avoir à rechercher l’adresse à chaque visite. Le contenu reste fourni par le site officiel : lorsqu’une nouvelle version est déployée, elle peut être récupérée par l’application web sans télécharger manuellement un nouveau fichier APK. Les fonctions disponibles restent les mêmes que sur la version web correspondante et nécessitent une connexion internet lorsque les services 3B doivent communiquer avec le serveur.

Si le bouton d’installation n’apparaît pas

Vérifiez que vous utilisez bien l’adresse officielle en HTTPS et un navigateur Android compatible. Rechargez la page puis consultez de nouveau le menu du navigateur. Selon l’appareil et la version du navigateur, l’intitulé peut être « Installer l’application », « Installer 3B International » ou « Ajouter à l’écran d’accueil ».

Google Play

Une version Android native destinée à Google Play est en préparation. Tant qu’aucune fiche officielle Google Play n’est publiée, la source officielle reste ce site. Une éventuelle version Play devra être annoncée directement depuis 3B International pour éviter toute confusion avec une copie.

Pourquoi utiliser la source officielle ?

Elle permet d’éviter les copies, les liens non vérifiés et les versions qui ne correspondent pas au projet officiel 3B International. Pour partager l’application, utilisez aussi la page Découvrir 3B, qui contient le lien officiel et un QR code permanent.
