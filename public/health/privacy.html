Le journal Santé

Le journal, l’énergie ressentie, les routines, les séances, les menus et les favoris restent sur ton appareil. Le mode temporaire est actif par défaut. La sauvegarde locale, facultative, conserve jusqu’à 90 jours de journal. Ce stockage local n’est pas chiffré par 3B ; évite de l’activer sur un appareil partagé.

Pas connectés dans la version native

Après ta demande explicite, 3B demande uniquement la lecture du nombre de pas via Health Connect sur Android ou Apple Santé sur iPhone. Aucune permission d’écriture, de localisation, de fréquence cardiaque ou de dossier médical n’est demandée par cette connexion. La lecture porte sur les 30 derniers jours, selon les données que le système rend accessibles.

Les totaux restent dans le journal local. Ils ne sont pas envoyés au serveur 3B, utilisés pour la publicité ou partagés avec les autres membres. Les permissions peuvent être gérées à tout moment dans les réglages santé du téléphone. Les statistiques de consultation 3B sont désactivées dans la rubrique Santé.

« Déconnecter » arrête les lectures et efface les pas importés de 3B. Les données d’origine dans Health Connect, Apple Santé, Samsung Health ou ta montre restent inchangées. Sur iPhone, tu dois retirer la permission système depuis Apple Santé ; 3B ne peut pas le faire à ta place. Un résultat vide ne permet pas de déduire si tu as refusé la lecture.

Rappels

Les notifications natives sont programmées uniquement après ton action et l’autorisation du téléphone. Elles utilisent un texte générique sans donnée de santé. Le téléphone conserve les horaires indépendamment du journal. Tu peux les annuler dans « Mes rappels ».

Sur le web, le fichier calendrier doit être importé volontairement dans ton application calendrier. Elle peut synchroniser les événements selon ses propres réglages. Ces événements ne contiennent aucune mesure de santé. Leur modification ou leur suppression se fait dans le calendrier.

Exporter ou effacer

Dans Santé → Mon journal et mes données, tu peux exporter les saisies ou effacer le journal et arrêter les lectures. L’effacement annule également les rappels natifs Santé. Un export téléchargé et les événements déjà importés dans un calendrier doivent être supprimés séparément.

Portée des outils

Ces outils de bien-être général ne posent pas de diagnostic. Le capteur web estime les mouvements uniquement pendant une session visible. Il peut se tromper et reste distinct des totaux du téléphone.
