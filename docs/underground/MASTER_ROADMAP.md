# 3B Underground — Master Roadmap

## Étape 1 — Fondations
- Architecture gameplay, carrière, sauvegarde, paramètres : codés.
- Catalogue 160 Gold Masters + catalogue étendu 1000 véhicules : structuré.
- Pipeline GLB/PBR/LOD/collision/cockpit : codé.

## Étape 2 — Véhicules et tuning
- 160 Gold Masters : fiches de production complètes.
- 5 variantes techniques S/GT/RS/X/Black Series par base.
- Tuning extrême multi-groupes : architecture prête.
- Reste : fabriquer les vrais GLB/PBR/LOD/cockpits/pièces 3D.

## Étape 3 — Carrière / Boss / économie
- Carrière 8 pays, événements, influence, fragments, boss de villes, gardiens, légendaires : systèmes codés.
- Missions race/escape/secret/boss : système codé.
- Économie sans pay-to-win, achat, réparation, revente : équilibrage initial codé.

## Étape 4 — Monde ouvert
- Plans 8 pays, biomes, routes, POI, cellules streaming : préparés.
- Police : graphe routier, cachettes, barrages, transitions territoires, recherche dynamique : codés.
- Reste : construire les environnements 3D finaux, routes et landmarks.

## Étape 5 — Conduite / IA
- Physique/tuning existants + dégâts et limp mode : codés.
- IA rivaux adaptative + phases boss : codées.
- Police : conduite, trafic, aérien, tactiques : codés.
- Reste : tests sur vraies routes et assets.

## Étape 6 — Présentation
- HUD course/monde, hooks audio dynamiques : modèles codés.
- Rendu Three.js premium existant, PBR/SSAO/bloom/pluie/sol mouillé : infrastructure existante.
- Reste : UI finale, vrais sons, musiques, animations, cinématiques, environnement final.

## Étape 7 — Qualité
- Game Health Monitor + Completion Director : codés.
- Budgets desktop/mobile et adaptation runtime : codés.
- Suites de tests Underground V2 + CI GitHub : branchées.
- Reste : E2E réel, captures gameplay réelles, profilage matériel, QA finale.

## État honnête
Le code et les systèmes sont beaucoup plus avancés que la production artistique. Le verrou principal reste la création et l'intégration des vrais assets 3D premium. Aucun concept art ni proxy n'est compté comme Gold Master final.
