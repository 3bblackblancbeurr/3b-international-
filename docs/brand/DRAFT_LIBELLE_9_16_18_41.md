# Projet de libellé — nouveau dépôt 3B (travail, non final)

Référence : Classification de Nice, version 2026.

> À copier dans un dépôt uniquement après validation dans l'outil de classification utilisé par l'INPI/EUIPO et après recherche d'antériorités. Le but est d'éviter un libellé trop large ou des termes non nécessaires.

## Classe 9 — cible minimale
- applications logicielles téléchargeables ;
- logiciels de jeux téléchargeables ;
- logiciels de jeux enregistrés ;
- logiciels d'application téléchargeables pour environnements virtuels.

### À rattacher à cette classe si effectivement distribués au téléchargement
- application mobile 3B ;
- jeux 3B distribués comme logiciels ;
- logiciels Windows 3B / outils créateurs ;
- version distribuée d'ALBERT sous une marque 3B, si elle est commercialisée comme logiciel téléchargeable.

## Classe 16 — cible minimale
- livres ;
- journaux de bandes dessinées ;
- livrets ;
- imprimés graphiques.

### Usages
- manga 3B imprimé ;
- artbooks ;
- livrets et publications physiques.

## Classe 18 — cible minimale
- sacs ;
- sacs à dos ;
- sacs à main ;
- sacs de sport ;
- sacs de voyage ;
- sacs de plage ;
- valises.

### À ajouter seulement si réellement prévu
- porte-documents ;
- porte-cartes.

## Classe 41 — formulations particulièrement pertinentes vérifiées dans la Classification de Nice
- services de jeu proposés en ligne à partir d'un réseau informatique ;
- services de divertissement ;
- services de divertissement fournis dans des environnements virtuels ;
- publication de livres ;
- mise à disposition de publications électroniques en ligne non téléchargeables ;
- mise à disposition en ligne d'images non téléchargeables ;
- mise à disposition en ligne de vidéos non téléchargeables ;
- production de films autres que films publicitaires ;
- réalisation de films autres que publicitaires.

### Usages
- Monde du 3B et jeux 3B en ligne ;
- manga consultable en ligne ;
- contenus vidéo 3B / 3B Origins TV ;
- expériences virtuelles de divertissement.

## Termes volontairement non ajoutés automatiquement
- services de jeux d'argent ;
- services sans rapport avec un usage 3B réel ;
- produits physiques de jeu (classe 28) tant que la gamme n'est pas verrouillée ;
- transmission/diffusion (classe 38) tant que 3B ne fournit pas lui-même un service de télécommunication ;
- réseau social (classe 45) tant que le service n'est pas qualifié juridiquement comme tel.

## Principe de réduction
Pour chaque terme, répondre à trois questions :
1. Est-ce que 3B l'exploite déjà ?
2. Est-ce que 3B a un plan sérieux et documenté pour l'exploiter ?
3. Est-ce nécessaire pour protéger le produit/service, ou une classe existante couvre-t-elle déjà le service réellement fourni ?

Si les réponses 1 et 2 sont toutes les deux non, retirer le terme.
