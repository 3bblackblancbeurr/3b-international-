# 3B International — guide d'usage de marque (interne)

## Mention officielle recommandée
**3B International — marque française enregistrée auprès de l'INPI sous le n° 5258267.**

Pour une version courte :
**3B International · INPI n° 5258267**

Ne pas écrire :
- « tout l'écosystème 3B est protégé par l'INPI » ;
- « breveté » ;
- « copyright INPI » ;
- « marque mondiale » tant que les protections correspondantes ne sont pas obtenues.

## Nom distinctif à privilégier publiquement
**3B International — Black • Blanc • Beur**

Le nom complet permet de distinguer le projet d'autres entités utilisant « 3B International ».

## Logo
- utiliser uniquement les fichiers officiels validés ;
- ne pas redessiner les lettres ;
- ne pas modifier les proportions ;
- ne pas ajouter un autre symbole dans le logo sans validation ;
- conserver une zone de respiration autour du signe ;
- ne pas transmettre les fichiers maîtres à un tiers sans préciser le cadre d'utilisation.

## Partenariats
Toute autorisation à un tiers doit préciser :
- le projet concerné ;
- les supports autorisés ;
- le territoire ;
- la durée ;
- le caractère exclusif ou non exclusif ;
- les fichiers autorisés ;
- la validation préalable des visuels ;
- l'interdiction de sous-licencier sans accord ;
- la fin automatique de l'usage après expiration/résiliation.

## Presse
Boilerplate recommandé :
> 3B International — Black • Blanc • Beur est un projet français qui relie mode, technologie, narration et communauté. Sa marque figurative française est enregistrée auprès de l'INPI sous le n° 5258267, pour les produits et services couverts par son enregistrement.

## Réseaux sociaux
Bio courte possible :
> 3B International — Black • Blanc • Beur
> Marque FR enregistrée · INPI n° 5258267
> Ce n'est pas une marque. C'est un héritage.

## Preuves d'usage
Archiver chaque usage significatif :
- date ;
- support ;
- URL / capture ;
- produit/service concerné ;
- classe correspondante ;
- facture/contrat si disponible.

Les preuves doivent être stockées dans le Brand Protection Vault privé et non dans un dépôt public si elles contiennent des informations personnelles ou commerciales confidentielles.
