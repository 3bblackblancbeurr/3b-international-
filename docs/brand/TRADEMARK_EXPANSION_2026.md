# 3B International — plan de protection complémentaire 2026

Date de travail : 29 septembre 2026

> Document de préparation. Il ne remplace pas une recherche d’antériorités complète ni un avis de CPI/avocat avant un dépôt important.

## 1. Deux dossiers juridiquement distincts

### A — Étendre la marque française actuelle n° 5258267 à l’étranger
- marque de base : marque figurative française 3B International ;
- dépôt français : 14 mai 2026 ;
- classes de base : 25, 35 et 42 ;
- échéance du droit de priorité de six mois : **14 novembre 2026** ;
- l’extension internationale doit reprendre le même signe et ne peut pas ajouter de nouveaux produits/services par rapport à la marque française de base ; une limitation reste possible.

### B — Protéger les nouvelles activités apparues après le dépôt
Les classes 9, 16, 18 et 41 ne peuvent pas être ajoutées à la marque n° 5258267. Elles nécessitent un **nouveau dépôt**. La date de priorité de ce nouveau dépôt sera sa propre date de dépôt.

## 2. Projet de libellé ciblé pour un nouveau dépôt

Le principe retenu est de viser les usages 3B réellement prévus, sans remplir les classes de termes inutiles.

### Classe 9 — logiciels et produits numériques téléchargeables
Projet de sélection à valider dans TMclass / Classification de Nice :
- applications logicielles téléchargeables ;
- logiciels de jeux téléchargeables ;
- logiciels de jeux enregistrés ;
- logiciels d’application téléchargeables pour environnements virtuels ;
- logiciels et programmes informatiques téléchargeables liés à l’accès, la gestion de compte, la fidélité, les expériences interactives et les outils créateurs, sous réserve de leur disponibilité dans le libellé accepté.

Usages 3B visés :
- application native/mobile si distribuée comme logiciel téléchargeable ;
- jeux 3B téléchargeables ;
- outils Windows ou logiciels 3B distribués au téléchargement.

### Classe 16 — manga, BD et imprimés
Projet de sélection :
- livres ;
- journaux de bandes dessinées ;
- imprimés graphiques ;
- livrets ;
- affiches et produits de l’imprimerie pertinents, après validation du libellé exact.

Usages 3B visés :
- Manga 3B / Le Cercle Brisé imprimé ;
- artbooks ;
- livrets, éditions physiques et supports imprimés.

### Classe 18 — sacs et maroquinerie pertinente
Projet de sélection :
- sacs ;
- sacs à dos ;
- sacs à main ;
- sacs de sport ;
- sacs de voyage ;
- sacs de plage ;
- valises ;
- porte-documents et porte-cartes si commercialisés sous 3B.

Usages 3B visés :
- sacs premium 3B ;
- bagagerie ;
- accessoires de transport / maroquinerie.

### Classe 41 — jeux, contenus et divertissement
Projet de sélection :
- services de jeu proposés en ligne à partir d’un réseau informatique ;
- publication de livres ;
- publication en ligne de livres et revues spécialisées électroniques ;
- mise à disposition de publications électroniques en ligne non téléchargeables ;
- mise à disposition en ligne de vidéos non téléchargeables ;
- réalisation et production de films autres que publicitaires, si effectivement exploitée ;
- services de divertissement liés aux expériences 3B, sous réserve du libellé précis retenu.

Usages 3B visés :
- Monde du 3B ;
- Jeux 3B en ligne ;
- Manga numérique non téléchargeable ;
- 3B Origins TV / contenus vidéo à la demande lorsque le service relève du divertissement.

## 3. Classes supplémentaires à étudier, sans dépôt automatique

### Classe 28
À étudier si 3B commercialise des jeux physiques, jeux de société, cartes à jouer/échanger, figurines ou appareils de jeux. La Classification de Nice place notamment les jeux de société, cartes à jouer et figurines d’action dans cette classe.

### Classe 38
À étudier si 3B fournit lui-même des services de diffusion/transmission, forums de discussion ou communication. À distinguer du contenu de divertissement lui-même, généralement classe 41.

### Classe 45
À étudier si 3B fournit un véritable service de réseautage social en ligne distinct du simple logiciel qui le permet.

## 4. Budget indicatif actuel

### Nouveau dépôt France — quatre classes 9 / 16 / 18 / 41
Tarification INPI actuellement publiée :
- première classe : 190 € ;
- chaque classe supplémentaire : 40 €.

Estimation pour 4 classes : **310 €** hors recherche d’antériorités, conseil et éventuelles autres formalités.

### Nouveau dépôt Union européenne — quatre classes
Tarification EUIPO actuellement publiée :
- 1re classe : 850 € ;
- 2e classe : +50 € ;
- 3e et chaque classe suivante : +150 €.

Estimation pour 4 classes : **1 200 €** hors conseil et recherche d’antériorités.

## 5. Extension internationale de la marque actuelle 25 / 35 / 42

Le système de Madrid peut être utilisé à partir de la marque française de base.

Émolument OMPI de base actuellement publié :
- 653 CHF si la représentation n’est pas en couleur ;
- 903 CHF si la représentation est en couleur.

S’ajoutent ensuite les taxes correspondant aux territoires désignés et, selon les membres, des taxes individuelles ou des compléments. Un calcul exact doit être refait avec le calculateur officiel au moment du dépôt.

### Périmètre 3B logique à comparer
- **Union européenne** : couvre notamment France, Espagne, Italie et Estonie via un seul titre régional ;
- **Türkiye** ;
- **Maroc** ;
- **Algérie** ;
- **Tunisie**.

Ces territoires figurent dans le système de Madrid, mais chaque office désigné conserve le pouvoir d’examiner/refuser la protection selon son droit.

## 6. Séquence de décision avant le 14 novembre 2026

1. verrouiller le fichier exact du signe enregistré en France ;
2. vérifier le certificat final et le libellé exact 25/35/42 ;
3. effectuer une recherche d’antériorités ciblée UE + Türkiye + Maroc + Algérie + Tunisie ;
4. calculer les taxes officielles exactes avec les calculateurs EUIPO/OMPI ;
5. décider si l’extension actuelle doit viser :
   - UE seulement ;
   - Madrid avec UE + pays hors UE ;
   - dépôts nationaux ciblés ;
6. déposer avant le 14 novembre si la priorité du 14 mai doit être revendiquée ;
7. traiter séparément le nouveau dépôt 9/16/18/41.

## 7. Décision à ne pas mélanger

**Ne pas retarder l’extension internationale 25/35/42 en attendant le nouveau dépôt 9/16/18/41.**

Les deux dossiers ont des objectifs et dates de priorité différents.
