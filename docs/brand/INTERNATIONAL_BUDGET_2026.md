# 3B International — budget et matrice territoriale de marque

Date de vérification : 29 septembre 2026

> Document de préparation fondé sur les barèmes officiels actuellement publiés. Les taxes peuvent évoluer : recalcul obligatoire sur les calculateurs officiels le jour d'un dépôt.

## 1. Marque actuelle à étendre avant le 14 novembre 2026

Marque de base :
- marque figurative française **3B International** ;
- INPI n° **5258267** ;
- dépôt : **14 mai 2026** ;
- classes actuelles : **25, 35, 42**.

Le délai de priorité de six mois expire le **14 novembre 2026**. Cette priorité concerne la même marque et les produits/services déjà couverts par le dépôt de base ; elle ne permet pas d'ajouter les nouvelles classes 9, 16, 18 ou 41.

## 2. Couverture correspondant aux 8 pays 3B

| Pays 3B | Voie régionale/internationale possible | Remarque |
|---|---|---|
| France | déjà couverte par la marque française | titre existant |
| Espagne | marque de l'Union européenne ou désignation UE via Madrid | UE |
| Italie | marque de l'Union européenne ou désignation UE via Madrid | UE |
| Estonie | marque de l'Union européenne ou désignation UE via Madrid | UE |
| Algérie | désignation Madrid | hors UE |
| Maroc | désignation Madrid | hors UE |
| Tunisie | désignation Madrid | hors UE |
| Türkiye | désignation Madrid | hors UE |

Une seule marque de l'Union européenne couvre les États membres de l'UE, donc notamment France, Espagne, Italie et Estonie.

## 3. Coût officiel actuel — marque UE directe, 3 classes

Barème EUIPO publié :
- 1re classe : **850 €** ;
- 2e classe : **+50 €** ;
- 3e classe et suivantes : **+150 € chacune**.

Pour les classes 25 / 35 / 42 :
- 850 + 50 + 150 = **1 050 €**.

Ce montant ne comprend pas un conseil professionnel, une recherche d'antériorités approfondie ou d'éventuelles procédures d'opposition.

## 4. Estimation Madrid — UE + Maroc + Tunisie + Türkiye + Algérie

La marque française étant déposée en couleurs noir/or, l'estimation utilise le barème de base Madrid **en couleur** actuellement publié.

### Émoluments OMPI utilisés pour cette simulation

- émolument de base couleur : **903 CHF** ;
- Union européenne, 3 classes : **981 CHF** ;
- Maroc, 3 classes : **287 CHF** ;
- Tunisie, 3 classes : **225 CHF** ;
- Türkiye, 3 classes : **230 CHF** ;
- Algérie : **100 CHF** de taxe complémentaire standard dans cette simulation, l'Algérie n'apparaissant pas dans le tableau actuel des taxes individuelles utilisé pour ce calcul.

Total indicatif :
**903 + 981 + 287 + 225 + 230 + 100 = 2 726 CHF**

À cela s'ajoute actuellement la redevance INPI française de transmission d'une demande internationale :
**62 €**.

### Important
Ce chiffre de **2 726 CHF + 62 €** est une simulation actuelle, pas un devis garanti. Utiliser le calculateur officiel OMPI juste avant paiement.

## 5. Variante : UE directe + Madrid seulement pour les quatre pays hors UE

Cette architecture peut être comparée à une désignation UE dans Madrid :

- marque UE directe 25/35/42 : **1 050 €** ;
- Madrid hors UE avec Maroc + Tunisie + Türkiye + Algérie :
  - base couleur 903 CHF ;
  - Maroc 287 CHF ;
  - Tunisie 225 CHF ;
  - Türkiye 230 CHF ;
  - Algérie 100 CHF ;
  - total indicatif : **1 745 CHF** ;
- transmission INPI : **62 €**.

L'intérêt n'est pas seulement le prix : il faut aussi comparer administration, dépendance à la marque de base pendant la période prévue par Madrid, renouvellements et stratégie de portefeuille.

## 7. SME Fund 2026

Le SME Fund 2026 prévoit normalement des remboursements pour certaines dépenses de propriété intellectuelle, mais le **voucher marques et dessins/modèles n'accepte actuellement plus de nouvelles demandes faute de budget disponible**.

Conséquence : ne pas construire le budget 3B en supposant un remboursement SME Fund. Surveiller uniquement une éventuelle réouverture officielle.

## 8. Matrice de décision

### Option A — France actuelle uniquement
Coût supplémentaire immédiat : 0 €.
Risque : la priorité internationale du 14 mai 2026 expire le 14 novembre 2026.

### Option B — marque UE actuelle 25/35/42
Budget officiel actuel : environ **1 050 €**.
Couverture : tous les États membres de l'UE.
À envisager uniquement après recherche d'antériorités et validation du signe/libellé.

### Option C — Madrid UE + MA + TN + TR + DZ
Budget OMPI indicatif : **2 726 CHF + 62 € INPI**.
Couverture ciblée : UE + quatre pays hors UE correspondant aux pays 3B concernés.
Recalcul officiel obligatoire avant paiement.

### Option D — UE directe + Madrid MA/TN/TR/DZ
Budget indicatif : **1 050 € + 1 745 CHF + 62 €**.
Permet de séparer le titre UE du portefeuille Madrid hors UE.

## 9. Ordre opérationnel recommandé avant paiement

1. récupérer/vérifier le certificat final et le libellé exact enregistré ;
2. verrouiller le fichier exact du logo/signe à étendre ;
3. faire une recherche d'antériorités exacte + similarité sur les territoires ciblés ;
4. choisir entre UE directe et désignation UE via Madrid ;
5. recalculer les taxes officielles le jour du dépôt ;
6. déposer avant le 14 novembre 2026 si la priorité du 14 mai doit être revendiquée ;
7. déposer séparément 9/16/18/41 après validation de leur libellé.
