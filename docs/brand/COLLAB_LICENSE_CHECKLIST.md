# 3B — checklist licence / collaboration de marque

> Checklist de préparation. Pour un contrat important, exclusif ou international, faire relire par un professionnel du droit.

## Identité des parties
- [ ] nom / raison sociale exacte
- [ ] représentant autorisé
- [ ] coordonnées professionnelles
- [ ] immatriculation si applicable

## Objet
- [ ] produit, contenu ou campagne précis
- [ ] marque(s) / logo(s) concernés
- [ ] références des fichiers officiels autorisés

## Droits accordés
- [ ] usage verbal
- [ ] usage du logo
- [ ] photographie / vidéo du produit
- [ ] publicité payante
- [ ] réseaux sociaux
- [ ] site / e-commerce
- [ ] packaging
- [ ] événement
- [ ] aucun autre usage

## Étendue
- [ ] territoire
- [ ] durée
- [ ] exclusif / non exclusif
- [ ] canaux autorisés
- [ ] volume ou série concernée
- [ ] droit de sous-licence : non par défaut

## Contrôle qualité
- [ ] validation préalable des maquettes
- [ ] échantillon/prototype si produit physique
- [ ] interdiction de modifier le logo
- [ ] normes de fabrication / sécurité
- [ ] retrait des supports non conformes

## Argent
- [ ] prix fixe / minimum garanti / royalties / autre
- [ ] assiette de calcul
- [ ] fréquence de reporting
- [ ] justificatifs de ventes
- [ ] échéance de paiement
- [ ] taxes et frais

## Propriété intellectuelle
- [ ] 3B conserve la propriété de la marque
- [ ] aucun transfert implicite
- [ ] propriété des créations nouvelles définie
- [ ] droit de réutiliser photos/contenus défini
- [ ] gestion des créations générées avec IA si concerné

## Fin du partenariat
- [ ] date de fin
- [ ] résiliation pour non-conformité
- [ ] délai d'écoulement des stocks
- [ ] suppression des logos/fichiers après fin
- [ ] traitement des contenus déjà publiés

## Confidentialité / données
- [ ] informations confidentielles identifiées
- [ ] données personnelles minimisées
- [ ] aucun accès inutile aux comptes 3B
- [ ] secrets/API jamais envoyés dans un contrat ou par e-mail

## Archivage
- [ ] contrat signé
- [ ] annexes
- [ ] visuels approuvés
- [ ] factures
- [ ] rapports de ventes
- [ ] preuves d'usage de la marque
