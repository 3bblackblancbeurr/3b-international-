# 3B International — brief de recherche d'antériorités

Objectif : vérifier les risques avant
1. l'extension internationale de la marque figurative actuelle 25/35/42 ;
2. un éventuel nouveau dépôt verbal « 3B International » ;
3. le nouveau dépôt 9/16/18/41.

## Territoires prioritaires
- France
- Union européenne
- Türkiye
- Maroc
- Algérie
- Tunisie

## Classes à vérifier en priorité
- existantes : 25, 35, 42
- nouvelles : 9, 16, 18, 41
- voisines à surveiller selon les produits : 28, 38, 45

## Requêtes exactes
- 3B INTERNATIONAL
- 3B International
- 3B
- 3-B INTERNATIONAL
- THREE B INTERNATIONAL
- BLACK BLANC BEUR

## Similarités à examiner
Ne pas limiter la recherche à l'identique. Examiner notamment :
- variations typographiques de 3B / 3-B / THREE B ;
- marques contenant 3B avec « International » ou un terme faiblement distinctif proche ;
- signes graphiques dominés par « 3B » dans les mêmes classes ;
- marques phonétiquement proches dans les langues/territoires visés ;
- marques antérieures dont les produits/services se recoupent avec l'habillement, logiciels, jeux, contenus, sacs, publicité et SaaS.

## Pour chaque résultat pertinent
Collecter :
- texte et représentation du signe ;
- office / territoire ;
- titulaire ;
- numéro ;
- statut ;
- date de dépôt / priorité ;
- classes ;
- libellé exact des produits/services pertinents ;
- lien vers la source officielle ;
- proximité visuelle, phonétique et conceptuelle ;
- recoupement produits/services ;
- observations factuelles uniquement.

## Sources à utiliser
Priorité aux bases officielles :
- INPI / base française ;
- EUIPO / TMview ou eSearch selon disponibilité ;
- OMPI Global Brand Database / Madrid Monitor ;
- offices nationaux lorsque nécessaire.

## Alerte déjà connue
Des sociétés utilisent publiquement le nom « 3B International » dans plusieurs pays. Cela ne permet pas, à lui seul, de conclure à un conflit de marque, mais renforce la nécessité d'une recherche officielle de droits antérieurs avant un dépôt verbal ou international.

## Critère de sortie
La recherche n'est « terminée » que lorsqu'on dispose :
- des résultats identiques ;
- des résultats similaires raisonnablement proches ;
- d'une lecture par classes/libellés ;
- d'un contrôle sur chaque territoire prioritaire ;
- d'un avis professionnel si un conflit sérieux apparaît.
