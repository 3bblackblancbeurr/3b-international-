# Albert APEX — Prestige Concierge V3

Nouvelle finition de l'interface basée sur le Concept 14 du propriétaire, construite sur la dernière version du Monde 3B.

- Portrait holographique : recadrage optimisé de l'image déjà présente dans 3B public/albert/command-center.png, stocké localement avec l'application ; portrait SVG conservé comme solution de repli.
- Quatre recommandations illustrées par de petites images locales : Voyage 3B, Santé, Jeux et Huit Royaumes. Il s'agit d'idées pour explorer, pas de données tirées du membre.
- Aperçu de timeline : uniquement les vraies activités choisies et enregistrées sur cet appareil, sans synchronisation, événements inventés ni notifications.
- Navigation Albert déportée au-dessus des panneaux Explorer et Ma journée afin de ne plus masquer les boutons ou les contenus.
- Sur mobile, scènes à hauteur d'écran et sans débordement horizontal ; aucun moteur WebGL supplémentaire.

Tests : revue visuelle et interactions sur 320x650, 390x844 et 1440x900 ; compilation, garde du système visuel et suite de tests du dépôt.

Important : il reste les essais physiques Samsung S21/Xiaomi pour vérifier fluidité réelle et rendu matériel.
Les API de paiement, le Passeport, les tables Supabase et les ports privés du véritable Albert PC restent inchangés. Aucun frais nouveau.
