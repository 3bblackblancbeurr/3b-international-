# Monde du 3B — état Gold Master au 28 septembre 2026

## Verdict

Le Monde du 3B est **jouable, déployé, sauvegardé et testé**, mais il n'est pas encore déclaré « terminé artistiquement à 100 % ».

## Couverture déjà présente

- 8 pays canoniques ;
- 8 profils cinématiques distincts ;
- 8 campagnes pays ;
- 8 monuments / patrimoines ;
- Hub / Cité des Huit Héritages ;
- PNJ, missions, secrets, événements ;
- météo, jour/nuit, eau, végétation ;
- ressources, refuges, expéditions ;
- combat, compagnons, Gardiens ;
- histoire Kaïs / Oubli / finale ;
- post-fin ;
- sauvegarde compte et hors ligne ;
- coopération et arène ;
- boutique Premium non pay-to-win ;
- builds web, Android et iOS couverts par CI.

## Décor

La structure des décors existe pour les huit pays et le Hub. Les pays disposent de quartiers étendus, patrimoine, rues, bâtiments, végétation et assets 3D.

Ce qui reste à produire pour une passe « grand studio » :
- plus de façades uniques ;
- plus de matériaux régionaux ;
- intérieurs visitables supplémentaires ;
- mobilier et petits détails par rue ;
- variations de densité / fréquentation ;
- meilleure continuité entre quartiers et points d'intérêt ;
- polish final lumière / brouillard / eau / météo pays par pays.

## Animation

Présent :
- avatar et déplacements ;
- compagnons / créatures animés ;
- actions de combat ;
- impacts / esquive / parade / pouvoirs ;
- PNJ en mouvement ;
- transports et éléments de monde.

À pousser :
- locomotion propre à chaque anatomie ;
- transitions animation → attaque → réception ;
- mains / armes mieux raccordées ;
- réactions terrain ;
- idle contextuels ;
- interactions PNJ plus riches ;
- animation faciale / regard pour les scènes importantes.

## Cinématiques

Le directeur cinématique couvre :
- première entrée d'un pays ;
- alliance narrative ;
- pouvoirs ;
- Souvenirs ;
- restaurations ;
- introduction Gardien ;
- introduction finale ;
- résultat de combat important ;
- premier lien compagnon ;
- découvertes ;
- finale.

Chaque pays a un profil caméra / lumière / VFX / rythme / son.

Restent à valider comme Gold Master :
- chorégraphie animation personnage dans chaque scène ;
- doublage / synchronisation voix définitive ;
- montage audio pays par pays ;
- transitions caméra sans collision sur tous les appareils ;
- cinématiques longues testées sur téléphone réel ;
- assets haute fidélité pour les moments principaux.

## Réseau / téléphone

La coopération existe, mais un monde partagé persistant libre n'est pas encore la promesse finale.

Avant Gold Master :
- sessions longues multi-joueurs ;
- reconnexion réseau faible ;
- appareils Android physiques milieu/bas de gamme ;
- iPhone physique ;
- mémoire GPU / chauffe / batterie ;
- sauvegarde après crash / reprise.

## Règle

Tant que cette passe n'est pas terminée, le projet doit être décrit comme **très avancé et jouable**, pas comme « totalement fini grand studio ».
