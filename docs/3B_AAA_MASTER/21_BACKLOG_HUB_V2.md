## Définition de fini

Une tâche n’est finie que si :

- le projet compile ;
- les tests passent ;
- les performances sont mesurées ;
- aucun comportement existant n’est cassé ;
- un appareil Android réel a été utilisé lorsque nécessaire ;
- la documentation est mise à jour ;
- un rollback est possible.
