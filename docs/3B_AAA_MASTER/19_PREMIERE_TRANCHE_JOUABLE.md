# 3B AAA MASTER — Première tranche jouable du hub

## But

Produire une boucle complète, mesurable et testable avant de construire toute la ville.

## Périmètre géographique

- Place de l’Héritage ;
- Tour du Cercle Brisé ;
- Archives de la Mémoire ;
- partie principale des Docks ;
- Portail Ville 3B ;
- approche de la Porte France ;
- approche de la Porte Algérie.

## Contenu minimum

### Population

- 20 profils de PNJ minimum ;
- 8 PNJ fonctionnels ;
- 6 PNJ narratifs ;
- 2 PNJ secrets ;
- 1 personnage rare de collection ;
- foule d’ambiance réglable selon le profil graphique.

### Missions

- Les premiers pas ;
- Le Premier Écho ;
- Les Toits du Cercle ;
- Le Bateau sans Pavillon ;
- au moins deux micro-événements ;
- au moins deux secrets sans marqueur initial.

### Transports

- marche/course/sprint Motion V2 ;
- un trajet réel en 3B Express ;
- un trajet réel en bateau-taxi ;
- une tyrolienne ;
- un téléphérique visible, puis utilisable si le budget le permet.

### Bâtiments utiles

- Tour du Cercle Brisé ;
- Maison de l’Accueil ;
- Archives ;
- Gare du 3B Express ;
- Gare maritime ;
- Bureau d’Urbanisme de Ville 3B ;
- Hôtel des Missions si le lot reste dans le budget.

## Parcours joueur de référence

1. connexion au compte ;
2. ouverture du Passeport ;
3. entrée dans le Monde du 3B ;
4. demande du mode paysage ;
5. arrivée sur la Place ;
6. interaction avec Maël Rivière ;
7. découverte du train ;
8. arrivée aux Archives ;
9. rencontre avec Inès Varga ;
10. mission Le Premier Écho ;
11. retour vers les Docks ;
12. bateau-taxi ;
13. découverte des silhouettes France et Algérie ;
14. récompense ;
15. sauvegarde ;
16. fermeture ;
17. reconnexion ;
18. progression restaurée ;
19. retour vers Ville 3B.

## Performance

### Android moyen

- 30 FPS stables minimum ;
- 3 cellules actives ;
- 10 à 18 PNJ proches ;
- 20 à 35 silhouettes distantes.

### Android haut de gamme

- mode 60 FPS lorsque possible ;
- 4 cellules actives ;
- 18 à 30 PNJ proches ;
- 35 à 60 silhouettes distantes.

### Desktop

- 60 FPS cible ;
- jusqu’à 6 cellules actives ;
- 30 à 50 PNJ proches.

## Définition de fini

La tranche n’est terminée que si :

- le build réussit ;
- les tests unitaires et d’intégration réussissent ;
- le parcours E2E réussit ;
- la sauvegarde et la reconnexion fonctionnent ;
- un Samsung réel a été testé ;
- aucun obstacle majeur ne bloque le déplacement ;
- les transports ne piègent pas le joueur ;
- la mémoire reste stable après plusieurs trajets ;
- les métriques avant/après sont documentées ;
- une procédure de rollback existe.

## Ce qui reste volontairement hors tranche

- les huit pays complets ;
- tous les bâtiments détaillés ;
- la totalité de la collection 241 ;
- météo avancée partout ;
- véhicules personnels complets ;
- foule maximale ;
- graphismes finaux de tous les quartiers.
