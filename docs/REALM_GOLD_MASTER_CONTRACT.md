# Monde 3B — contrat Gold Master des royaumes

France est la référence industrielle. Les sept autres royaumes ne sont pas sept prototypes indépendants.

Un royaume n'est déclaré Gold Master que si tous les gates suivants sont satisfaits :
- environnement final ;
- Gardien final ;
- chaîne de quêtes ;
- combat ou épreuve de valeur ;
- cinématique d'arrivée ;
- cinématique Gardien ;
- Fragment attribué une seule fois ;
- retour Hub ;
- évolution visible du Hub ;
- audio ;
- budget mobile ;
- sauvegarde/restauration ;
- autorité serveur ;
- accessibilité.

Ordre de production :
France → Algérie → Espagne → Maroc → Italie → Tunisie → Turquie → Estonie.

Les sept royaumes héritent du contrat technique France, mais conservent leur propre direction artistique, mécanique de valeur, Gardien et narration.
